# Сайт 4Kath Studio — размещение на GitHub Pages

Сайт статичный: три HTML-страницы и картинки, сборка не нужна.


## Что внутри архива

- index.html — английская версия (главная страница сайта).
- ru.html и es.html — русская и испанская версии. Переключатель EN / RU / ES в шапке ведёт на них.
- assets/img — все картинки сайта с понятными именами (work-…, case-…, team-…, logo-…, pay-…, avatar-…).
- assets/fonts — шрифт Evolventa (обычный и жирный).
- CNAME — в нём записан домен 4kath.com. Нужен GitHub, чтобы сайт открывался по вашему домену.
- .nojekyll и 404.html — служебные файлы. .nojekyll отключает лишнюю обработку на GitHub, 404.html возвращает на главную при неверной ссылке.

## Шаг 1. Создайте репозиторий

1. Зайдите на github.com под своим аккаунтом (если аккаунта нет — Sign up, это бесплатно).
2. Справа вверху нажмите «+» → New repository.
3. Repository name: 4kath-site. Видимость: Public (бесплатный хостинг GitHub Pages работает с публичными репозиториями).
4. Галочку Add a README не ставьте. Нажмите Create repository.

## Шаг 2. Загрузите файлы

1. Распакуйте архив 4kath-site.zip у себя на компьютере.
2. На странице нового репозитория нажмите ссылку uploading an existing file (или Add file → Upload files).
3. Перетащите в окно СОДЕРЖИМОЕ папки 4kath-site: index.html, ru.html, es.html, 404.html, CNAME, .nojekyll и папку assets. Саму папку 4kath-site перетаскивать не нужно, иначе сайт окажется во вложенной папке.
4. Файл .nojekyll скрытый. На Mac нажмите Cmd + Shift + . в Finder, чтобы его увидеть. На Windows: Проводник → Вид → Скрытые элементы.
5. Внизу нажмите Commit changes.

## Шаг 3. Включите GitHub Pages

1. В репозитории откройте Settings → Pages (в левом меню).
2. Source: Deploy from a branch. Branch: main, папка / (root). Нажмите Save.
3. Через 1–2 минуты вверху страницы появится адрес вида https://ВАШ-ЛОГИН.github.io/4kath-site/. Откройте его и проверьте сайт.

## Шаг 4. Подключите домен 4kath.com

1. В Settings → Pages в поле Custom domain впишите 4kath.com и нажмите Save. Файл CNAME уже лежит в репозитории, поэтому поле может заполниться само.
2. Зайдите в панель регистратора, где куплен домен, раздел DNS.
3. Удалите старые A-записи для корня домена (@), если они есть.
4. Добавьте 4 A-записи для @: 185.199.108.153, 185.199.109.153, 185.199.110.153, 185.199.111.153.
5. Добавьте CNAME-запись: имя www, значение ВАШ-ЛОГИН.github.io (с вашим логином на GitHub).
6. По желанию добавьте AAAA-записи для @ (IPv6): 2606:50c0:8000::153, 2606:50c0:8001::153, 2606:50c0:8002::153, 2606:50c0:8003::153.
7. DNS обновляется от нескольких минут до 24 часов. Когда GitHub в Settings → Pages напишет, что проверка DNS прошла, поставьте галочку Enforce HTTPS.

## Шаг 5. Защитите домен (рекомендуется)

1. В настройках аккаунта (не репозитория): аватар справа вверху → Settings → Pages → Add a domain.
2. Впишите 4kath.com. GitHub покажет TXT-запись — добавьте её у регистратора в DNS и нажмите Verify.
3. Так никто другой не сможет подключить ваш домен к своему репозиторию.

## Как обновлять сайт

- Поменять текст: откройте нужный файл в репозитории (index.html, ru.html или es.html) → значок карандаша → найдите текст (Ctrl/Cmd + F) → исправьте → Commit changes. Изменения появятся на сайте через 1–2 минуты.
- Заменить картинку: загрузите новую картинку в папку assets/img с ТЕМ ЖЕ именем файла (Add file → Upload files). Старая заменится автоматически.
- Текст на трёх языках правится в трёх разных файлах: если меняете цену или условия, поправьте все три.
- Если сайт не обновился, обновите страницу с очисткой кэша: Cmd + Shift + R (Mac) или Ctrl + F5 (Windows).

## Что пока не подключено

- Ссылки Terms of use, Privacy policy и Refund policy в футере никуда не ведут — страниц с этими условиями пока нет.
- Кнопки Book a call и «Записаться на звонок» открывают письмо на 4kath.studio@gmail.com. Если появится форма записи (Calendly и т. п.), ссылку можно заменить.
- Аналитики (Google Analytics, Яндекс Метрика) на сайте нет. Её код можно вставить перед строкой </head> во все три файла.
